# 프로스피 한국어 자막

프로스피 PC판의 일본어 해설을 한국어 자막으로 표시하는 비공식 프로그램입니다. 여러 사용자 PC에서 연결·출력을 확인하기 위한 **알파 테스트** 단계입니다.

## 다운로드

[알파 0.4.2 다운로드](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.4.2-alpha)

릴리스 페이지의 **Assets**에서 **ProspiSubtitles-Alpha-0.4.2.zip**을 받으세요. `Source code` ZIP은 실행 프로그램이 아닙니다. [이전 알파 0.4.1](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.4.1-alpha)도 유지합니다.

## 실행

1. ZIP 전체를 쓰기 가능한 일반 폴더에 압축 해제합니다.
2. `ProspiSubtitles.exe`를 실행합니다. EXE만 따로 옮기지 마세요.
3. 게임을 실행하고 일본어 해설이 나오는 경기를 진행합니다. 게임 경로는 자동으로 찾습니다.
4. 미리보기를 켰다면 **미리보기 끄기**를 눌러 실제 해설로 돌아갑니다.
5. **자막 박스 위치 · 크기 조절**로 자막 배치를 맞춥니다.

Windows 10/11 64비트용입니다. 별도 Python·ChatGPT·API 키 설치가 필요 없습니다. 설정창은 마우스로 크기 조절·최소화·최대화가 가능하며, 최소화해도 자막은 계속 표시됩니다. X 버튼으로 프로그램과 자막 박스를 함께 종료합니다.

이전 버전을 종료하고 새 ZIP을 별도 폴더에 압축 해제하세요. 기존 `settings.json`을 복사하면 배치 설정을 유지할 수 있습니다. 자동 업데이트는 없습니다.

## 0.4.2 변경 내용

- 최신 검수본의 일반 음원 자막 **51,219개**를 수록했습니다.
- 소개형 기본 문형 **3,207개**, 변주 **375개**를 수록했습니다. 선수 소개·투수 교체 등 게임에서 읽힌 문장과 재생 번호를 대응시켜 표시합니다.
- **이름 감지 내역 / 등록한 이름 관리**에서 이름 저장·수정·삭제를 할 수 있습니다.
- 감독 이름을 일괄 생략하던 **107개 문형**을 보완했습니다. 읽힌 발음과 사용자 지정 이름을 반영하며, 발음을 알 수 없는 한자 이름은 추측하지 않습니다.
- 이름 관리 두 창의 ‘표기 기준’ 열을 제외했습니다. 내부 이름 처리 우선순위는 유지합니다.
- 기존 창 크기 조절·자막 박스 조절·자동 진단 기능을 유지합니다.

이름은 사용자 지정 → 기존 사전 → 발음 근사 순으로 표시하며, 실제 이름과 다를 수 있습니다. 같은 호명 발음은 같은 지정 표기를 공유합니다. 변경은 잠시 후 새로 시작되는 소개형 자막부터 적용됩니다. 최근 자막 보기·F8 검수 기능·화면의 [소개] 표시는 배포판에 포함하지 않습니다.

## 저장 위치

**이름 설정과 감지 기록:** 게임 설치 드라이브의 `프로스피 한국어 자막\이름 설정` 폴더. 예: `D:\프로스피 한국어 자막\이름 설정`. 설정창에 실제 위치와 **이름 저장 폴더 열기** 버튼이 있습니다. 게임 위치 미확인·쓰기 실패 때 다른 위치로 대체 저장하지 않습니다. 프로그램 폴더의 `저장위치.json`에는 드라이브 정보만 둡니다.

**자동 진단 ZIP:** 기존처럼 바탕화면의 **프로스피 자막 진단** 폴더. 연결 후 1분마다 같은 실행의 ZIP을 갱신합니다. **진단 ZIP 삭제**는 해당 ZIP을 지우고 자동 저장을 끕니다. 자막·이름 설정은 삭제하지 않습니다. 저장 실패 때 다른 위치로 우회 저장하지 않습니다.

제거할 때는 프로그램을 종료한 뒤 압축 해제한 폴더를 삭제하세요. 이름 자료도 지우려면 게임 드라이브의 위 이름 설정 폴더를 별도로 삭제하면 됩니다. 진단 ZIP은 바탕화면의 진단 폴더에서 삭제할 수 있습니다.

## 문제 제보

**진단 ZIP을 반드시 첨부**하고 게임 버전·사용 중인 패치 종류·발생 상황을 알려 주세요. 자동 저장을 꺼두었다면 켜고 문제를 재현한 뒤 **최소 1분 후** ZIP을 받아 주세요. 화면 잘림은 Windows 화면 배율과 접근성 텍스트 크기도 함께 알려 주세요.

진단에는 최근 표시 문구, 음원·재생 번호, 소개형 문형과 오류·표시 위치가 포함됩니다. 공개 게시판에 첨부하기 전에 내용을 확인해 주세요. **음성 녹음·화면 캡처·자동 전송은 하지 않습니다.** 정상 종료 시 임시 실행기록을 정리합니다.

평소 사용하던 화면 설정으로 실행하세요. 자막이 보이지 않거나 게임 뒤로 가는 경우에만 테두리 없는 전체화면 또는 창 모드 전환을 임시 해결 방법으로 시도해 주세요.

## 확인 범위

현재 개발 PC의 일반 연결·소개형 코드 검사, 등록 문형 출력 예제, 이름 저장·수정·삭제, 설정창 크기 변경·종료와 진단 기능을 검사했습니다. 감독 이름 수정은 텍스트·출력 대조이며 새 청음 검수는 아닙니다. 다른 PC와 실제 경기의 전체 출력, 모든 게임 업데이트·패치 호환은 추가 확인이 필요합니다. 미등록·오역과 발음 변환 실패가 남아 있습니다.

게임 데이터는 읽기 전용으로 확인합니다. 실행 중 음성 인식·온라인 번역·유료 API를 호출하지 않으며, 원본 음원과 개인 경기 기록·개인 이름 DB를 배포하지 않습니다. 게임만 관리자 권한으로 실행했다면 자막 프로그램도 같은 권한이 필요할 수 있습니다.

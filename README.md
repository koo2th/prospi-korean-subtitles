# 프로스피 한국어 자막

프로스피 PC판의 일본어 해설을 한국어 자막으로 표시하는 비공식 프로그램입니다. 여러 사용자 PC에서 연결·출력을 확인하기 위한 **알파 테스트** 단계입니다.

## 다운로드

[**알파 0.4.2 다운로드**](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.4.2-alpha) · [이전 0.4.1](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.4.1-alpha)

릴리스 페이지의 **Assets**에서 **ProspiSubtitles-Alpha-0.4.2.zip**을 받으세요. Source code ZIP은 실행 프로그램이 아닙니다.

## 실행

1. ZIP **전체를** 쓰기 가능한 일반 폴더에 압축 해제합니다.
2. `ProspiSubtitles.exe`를 실행합니다. EXE만 따로 옮기지 마세요.
3. 게임을 실행하고 일본어 해설이 나오는 경기를 진행합니다. 게임 경로는 자동으로 찾습니다.
4. 미리보기를 사용했다면 **미리보기 끄기**를 눌러 실제 해설로 돌아갑니다.
5. **자막 박스 위치 · 크기 조절**로 배치를 맞춥니다.

Windows 10/11 64비트용입니다. Python·ChatGPT·AI 모델·API 키 설치가 필요 없습니다. 설정창은 마우스로 크기 조절·최소화·최대화할 수 있으며, 최소화해도 자막은 계속 표시됩니다. X 버튼으로 프로그램과 자막 박스를 함께 종료합니다.

기존 버전을 종료하고 새 ZIP을 별도 폴더에 압축 해제하세요. 이전 `settings.json`을 복사하면 자막 배치를 유지할 수 있습니다. **자동 업데이트는 없습니다.** 자세한 설명은 ZIP 안의 **사용방법.txt**를 참고하세요.

## 0.4.2 주요 내용

- 일반 음원 자막 **51,219개**, 소개형 기본 문형 **3,210개**와 변주 **375개**를 수록했습니다. 문형 수는 모든 가능한 소개 문장의 수를 뜻하지 않습니다.
- 선수 소개·교체·타선과 배터리·상대 전적·앞선 타석 설명 등 소개형 해설을 추가·보완했습니다.
- **이름 감지 내역 / 등록한 이름 관리**에서 이름을 저장·수정·삭제할 수 있습니다.
- 감독 이름, 홈팀·원정팀, 일부 발음 변환, 이어 붙은 팀명과 사람 이름의 구분을 보완했습니다.
- 마지막 사용자 청음 수정 두 문구와 동일 음원 중복분, 총 **5개 ID**를 반영했습니다.
- 소개형 해설 코드 위치가 이동했을 때 구조를 검증해 다시 찾도록 보완했습니다. 소개형 연결 검사에 실패해도 일반 음원 자막 처리를 이어갑니다.
- 기존 설정창·자막 박스 조절과 자동 진단 기능을 유지합니다.

이름은 **사용자 지정 → 기존 사전 → 한글 발음 근사** 순으로 표시합니다. 발음 근사는 실제 이름과 다를 수 있고 같은 호명 발음에는 같은 지정 표기가 적용됩니다. 변경은 새로 시작되는 소개형 자막부터 반영됩니다.

기존 사전의 선수·팀 이름은 감지 목록에서 숨기되 기록은 보존합니다. 사전 이름에 대해 사용자가 직접 저장한 설정은 **등록한 이름 관리**에서 계속 수정·삭제할 수 있습니다. 문장만으로 팀명·사람 이름의 경계를 구분하기 어려우면 잘못 붙여 표시하지 않고 보류합니다.

개인 검수용 최근 자막 보기·F8 기능·[소개] 표시는 배포판에 포함하지 않았습니다.

## 저장 위치와 제거

- **이름 설정·감지 기록:** 게임 설치 드라이브의 `프로스피 한국어 자막\이름 설정` 폴더. 예: `D:\프로스피 한국어 자막\이름 설정`. 설정창에서 실제 위치를 확인하고 폴더를 열 수 있습니다. 게임 위치 미확인·쓰기 실패 시 다른 위치로 대체 저장하지 않습니다.
- **자동 진단 ZIP:** 바탕화면의 **프로스피 자막 진단** 폴더. 연결 후 1분마다 같은 실행의 ZIP을 갱신합니다. **진단 ZIP 삭제**는 해당 ZIP을 지우고 자동 저장을 끕니다. 자막·이름 설정은 지우지 않습니다.

프로그램을 제거하려면 종료한 뒤 압축 해제한 폴더를 삭제하세요. 이름 자료와 진단 ZIP도 지우려면 위 저장 폴더에서 별도로 삭제하면 됩니다.

## 오류 제보

**진단 ZIP을 반드시 첨부**하고 게임 버전·사용 중인 패치 종류·발생 상황을 알려 주세요. 자동 저장을 껐다면 켜고 문제를 재현한 뒤 **최소 1분 후** ZIP을 받아 주세요. 화면 잘림은 Windows 화면 배율과 접근성 텍스트 크기도 함께 알려 주세요.

진단에는 최근 표시 문구, 음원·재생 번호, 소개형 문형과 오류 정보가 포함됩니다. 공개 첨부 전에 내용을 확인해 주세요. **음성 녹음·화면 캡처·자동 전송은 하지 않습니다.**

평소 사용하던 화면 설정으로 실행하세요. 자막이 보이지 않거나 게임 뒤로 가는 경우에만 화면 모드 전환을 임시 해결 방법으로 시도해 주세요.

## 확인 범위

현재 개발 PC에서 일반·소개형 해설의 읽기 전용 연결, 코드 위치 이동 모의 시험, 등록 문형과 기록의 출력 재현, 이름 저장·수정·삭제, 창 크기 변경·종료 및 진단 기능을 검사했습니다. **모든 사용자 PC·게임 업데이트·패치의 호환이나 전체 문장의 정확성을 보장하지는 않습니다.** 미등록 문형과 오역은 남아 있습니다.

게임 파일을 수정하거나 다른 패치를 설치·교체하지 않습니다. 실행 중 음성 인식·온라인 번역·유료 API 호출을 하지 않으며, 원본 음원과 개인 이름 DB는 배포하지 않습니다. 게임만 관리자 권한으로 실행한 경우 자막 프로그램도 같은 권한이 필요할 수 있습니다.

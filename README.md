# 프로스피 한국어 자막

프로스피 PC판의 일본어 해설을 한국어 자막으로 표시하는 비공식 프로그램입니다. 현재 **베타 0.5.0**을 배포하고 있습니다.

## 다운로드

[**베타 0.5.0 다운로드**](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.5.0-beta) · [이전 알파 0.4.2](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.4.2-alpha)

릴리스 페이지 아래 **Assets → ProspiSubtitles-Beta-0.5.0.zip**을 받으세요. `Source code`는 실행용 프로그램이 아닙니다. `beta-data.zip`은 프로그램이 처리하는 번역 DB 업데이트 파일이므로 실행용 ZIP 대신 받지 마세요.

## 실행·알파에서 교체

1. 기존 자막 프로그램을 완전히 종료합니다.
2. ZIP 전체를 압축 해제합니다. 알파 사용자는 ZIP 안의 파일과 폴더를 **기존 프로그램 폴더 안에 덮어씌우세요.**
3. `ProspiSubtitles.exe`를 실행합니다. EXE만 따로 옮기지 마세요.
4. 게임에서 일본어 해설을 켜고 경기를 시작합니다. 자막 박스 위치·크기와 글꼴은 설정창에서 조절합니다.

Windows 10/11 64비트용입니다. Python·ChatGPT·AI 모델·API 키를 별도로 설치할 필요가 없습니다. 자막 프로그램은 한 개만 실행하세요.

ZIP에 `settings.json`과 개인 데이터를 넣지 않아 기존 자막 설정을 유지합니다. 알파의 이름 설정은 기존 저장 위치 또는 게임 연결 경로를 바탕으로 베타 폴더로 가져옵니다. 이미 베타에서 지정한 이름은 우선 보존합니다.

## 베타 주요 기능

- 일반 해설과 선수 소개·교체 등 소개형 해설 자막, 감지된 이름의 표기 지정·관리
- 새 **번역 DB** 알림과 사용자 선택에 따른 업데이트 적용
- 최근 자막에서 선택한 문장 오역 제보, **F8**으로 확인할 위치 표시
- **이전 오류 / 다음 오류**로 F8 표시 위치 이동
- 자막·이름·업데이트/진단 탭으로 정리한 설정창
- 창 크기 조절·최대화, 최소화 시 트레이 이동

최소화해도 자막은 계속 표시됩니다. 트레이 아이콘을 두 번 누르면 설정창이 돌아옵니다. X 또는 트레이의 프로그램 종료는 자막까지 종료합니다.

## 번역 DB 업데이트

기본 DB는 알파 0.4.2의 **일반 자막 51,219개 / 소개형 기본 문형 3,210개·변주 375개**입니다. 게시된 새 DB를 적용하면 추가·수정된 번역을 받을 수 있습니다. 미등록·오역은 계속 보완 중입니다.

실행 시와 실행 중 새 DB를 확인합니다. 자동 확인은 최소 **6시간**, 수동 확인은 **10분** 간격입니다. 게시 즉시 모든 사용자에게 알림을 보내는 방식은 아닙니다.

새 DB가 있으면 같은 버전의 알림을 한 번 띄웁니다. **업데이트 적용**을 눌러 다운로드·검사를 마치면 다음 게임 연결부터 사용합니다. 적용한 버전은 저장되므로 같은 DB를 다시 새 업데이트로 안내하지 않습니다. 자막 설정과 지정 이름은 유지합니다. **프로그램 자체의 새 버전은 별도로 받아 교체합니다.**

## 오류 제보

게임 중 **F8**은 나중에 확인할 위치만 표시합니다. 게임을 멈추거나 제보 창을 열지 않으며, F8만 눌러서는 전송되지 않습니다. 이후 **최근 자막·오류 제보**에서 문장을 선택하고 오류 제보를 누르세요. 코멘트 입력은 없습니다.

제보에는 선택 자막, 음원 또는 문형 식별 정보, 번역 버전 등이 포함됩니다. 소개형 이름 자리의 출력 이름은 가려 보냅니다. **음성·화면·게임 파일·이름 설정 전체는 자동 업로드하지 않습니다.** 미등록 음원 자동 제보와 자막 직접 수정 기능은 없습니다.

연결 실패·무료 서버 한도 도달 시 전송 대기로 남아 프로그램 실행 중 재시도합니다. 제보 대기는 최대 14일입니다. 실행·연결 오류는 생성된 **진단 ZIP**, 게임 버전·패치 종류·발생 상황을 함께 알려주세요. 화면 잘림은 Windows 배율과 텍스트 크기도 알려주시면 도움이 됩니다.

## 저장·삭제

베타 설정은 프로그램 폴더의 `settings.json`에, 이름·최근 자막·제보 대기열·갱신 DB는 `사용자 데이터` 폴더에 저장합니다. 최근 자막은 최대 14일/10,000개 범위로 보관합니다. 실제 오류가 발생하거나 진단 저장을 실행할 때 `진단` 폴더를 만듭니다.

베타를 완전히 종료한 뒤 프로그램 폴더를 삭제하면 베타가 만든 로컬 자료도 함께 삭제됩니다. **알파가 외부에 만들었던 이름·진단 폴더는 자동 삭제하지 않습니다.** 서버에 이미 접수된 제보도 로컬 삭제로 취소되지 않습니다.

게임 파일을 수정하거나 다른 패치를 설치·교체하지 않습니다. 게임 업데이트에 따라 자막 프로그램 보완이 필요할 수 있습니다. 평소 사용하는 화면 모드로 실행하고, 자막이 게임 뒤로 가거나 보이지 않을 때 화면 모드 전환을 임시 해결 방법으로 시도해 주세요.

자세한 내용은 ZIP 안의 **사용방법.txt**와 [베타 변경 안내](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.5.0-beta)를 확인하세요.

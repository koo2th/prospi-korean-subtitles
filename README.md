# 프로스피 한국어 자막

프로스피 PC판의 일본어 해설을 한국어 자막으로 표시하는 비공식 프로그램입니다. 현재는 여러 PC와 게임 패치 환경에서 연결·출력을 확인하기 위한 **알파 테스트** 단계입니다.

## 다운로드

[알파 0.4.0 다운로드](https://github.com/koo2th/prospi-korean-subtitles/releases/tag/v0.4.0-alpha)

릴리스 페이지의 **Assets**에서 `ProspiSubtitles-Alpha-0.4.0.zip`을 받으세요. `Source code` ZIP은 실행 프로그램이 아닙니다.

## 실행 방법

1. 다운로드한 ZIP **전체를** 쓰기 가능한 일반 폴더에 압축 해제합니다.
2. `ProspiSubtitles.exe`를 실행합니다. EXE만 따로 옮기지 마세요.
3. 게임을 실행하고 **일본어 해설**이 나오는 경기를 진행합니다. 게임 설치 경로는 자동으로 찾습니다.
4. 미리보기로 자막 위치를 확인했다면 **미리보기 끄기**를 눌러 실제 해설로 돌아갑니다.
5. **자막 위치 · 크기 조절**에서 배치를 맞추고 편집을 완료합니다.
6. 프로그램 창의 X 버튼으로 자막 박스와 연결을 함께 종료합니다.

Windows 10/11 64비트용입니다. Python·ChatGPT 설치나 API 키가 필요하지 않습니다. 창 모드 또는 테두리 없는 창 모드를 권장합니다.

## 어떤 방식인가요?

실제 출력 소리를 녹음하거나 음성 인식하는 방식이 아닙니다. 게임에서 재생 중인 해설 ID를 읽고, 그 ID에 대응하는 한국어 문장을 표시합니다. 관중 소리와의 음성 지문 비교는 하지 않습니다.

알파 0.4.0에는 현재 프로그램에 반영된 자막 **46,174개**가 들어 있습니다. 미등록 해설, 잘못된 번역, 미확인 표현이 남아 있을 수 있습니다.

## 연결·출력에 문제가 있다면

**자동 진단 ZIP 저장**이 켜져 있으면 연결 시작 후 1분마다 바탕화면의 **프로스피 자막 진단** 폴더에 ZIP을 저장합니다. 같은 실행 중에는 같은 ZIP을 갱신합니다.

- **진단 폴더 열기**: 저장된 ZIP을 확인합니다.
- **진단 ZIP 삭제**: 해당 진단 파일을 지우고 자동 저장도 끕니다. 자막 데이터와 설정은 유지됩니다.
- 자동 저장을 꺼도 자막 프로그램은 계속 사용할 수 있습니다. 다시 켜야 ZIP 저장이 재개됩니다.
- 파일 탐색기에서 직접 삭제해도 됩니다. 다시 생기지 않게 하려면 자동 저장을 먼저 끄세요.
- 바탕화면 저장에 실패하면 다른 위치로 우회 저장하지 않고 화면에 오류를 표시합니다.

진단에는 해설 ID, 일치 여부, 최근 표시 문구, 프로그램 버전, 표시 위치와 오류 정보가 포함됩니다. **음성 녹음·화면 캡처·자동 전송은 하지 않습니다.** 정상 종료 시 임시 실행기록을 정리합니다.

문제 제보 시 게임 버전, 사용하는 패치 종류, 발생 상황을 적고 필요한 경우 진단 ZIP을 직접 전달해 주세요. 공개 게시판에 첨부하면 누구나 내용을 볼 수 있으므로 ZIP 안의 내용을 먼저 확인해 주세요.

## 현재 확인 범위

- 현재 개발 PC에서 실제 게임 연결과 해설 메모리 구조 검사를 확인했습니다.
- 보관 기록을 이용한 자막 선택·표시 시간 테스트, 미리보기 표시 요청, 진단 생성·삭제 범위 및 종료 정리를 확인했습니다.
- 다른 PC의 패치 환경과 실제 경기 중 전체 해설 출력은 추가 확인이 필요합니다.
- 실행 파일 크기가 달라도 해설 코드와 구조가 맞으면 연결하지만, **모든 업데이트·패치와의 호환을 보장하지는 않습니다.**
- 게임만 관리자 권한으로 실행한 경우 자막 프로그램도 같은 권한이 필요할 수 있습니다.

이번 알파에는 개인 검수용 최근 자막/오류 작성 화면과 자동 업데이트는 포함하지 않았습니다. 실행 시 유료 API를 호출하지 않으며, 게임 원본 음원과 개인 경기 기록은 배포본에 포함하지 않았습니다.
